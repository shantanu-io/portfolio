SQL Analysis: Revenue, Customers, Category Share

SQL · CTEs · Window functions (LAG, RANK)

Three reporting queries on a 600-row orders table. The outputs below are real results from running these queries.

Monthly revenue and growth

WITH m AS (
  SELECT strftime('%Y-%m', order_date) AS month,
         SUM(amount) AS revenue
  FROM orders
  GROUP BY 1
)
SELECT month, revenue,
       ROUND(100.0 * (revenue - LAG(revenue) OVER (ORDER BY month))
             / LAG(revenue) OVER (ORDER BY month), 1) AS mom_growth_pct
FROM m
ORDER BY month
LIMIT 5;

Data Cleaning with Pandas

Python · Pandas · Data cleaning

A messy order export cleaned in one short script: 6 duplicate rows removed, customer names standardised, rupee-formatted text converted to numbers, 21 missing or invalid amounts filled with the category median, and unusable dates dropped.

import pandas as pd

df = pd.read_csv("orders_raw.csv")
df = df.drop_duplicates()                                   # remove repeated rows
df["customer"] = (df["customer"].str.strip()
                  .str.replace(r"\s+", " ", regex=True).str.title())
df["amount"] = pd.to_numeric(
    df["amount"].astype(str).str.replace("₹", "").str.replace(",", ""),
    errors="coerce")                                        # "₹1,200" -> 1200
df["amount"] = df["amount"].fillna(
    df.groupby("category")["amount"].transform("median"))   # fill missing values
df["date"] = pd.to_datetime(df["date"], dayfirst=True,
                            format="mixed", errors="coerce")
df = df.dropna(subset=["date"])                             # drop unusable dates
